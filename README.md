# AnimalVision AI — Trained Snapshot

This repository is a larger working snapshot of [AnimalVision AI](https://github.com/shxhxn/animalvision-ai) that includes generated model and demo artifacts.

For the clean, canonical source code, setup guide, and ongoing project documentation, use:

**[shxhxn/animalvision-ai](https://github.com/shxhxn/animalvision-ai)**

## What is included

- Flask prediction interface
- Custom TensorFlow/Keras CNN source
- Training and evaluation pipeline
- Generated model and supporting artifacts used during development

The canonical repository intentionally keeps source and generated artifacts separate so the project is easier to review and reproduce.
